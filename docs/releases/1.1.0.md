## Batas verifikasi

- Pengujian fungsional sebelumnya pada APK debug sudah membuktikan pemasangan widget, transaksi tersimpan di Supabase, dan perubahan Rp0 menjadi Rp25rb/1 transaksi beserta mood, saran, dan maskot.
- Cold-start/smoke test ulang untuk APK release belum dilakukan: RAM host yang tersedia terukur hanya 386 MB, sehingga emulator release tambahan tidak dijalankan. Emulator/data debug yang ada tidak dihapus atau dihentikan.
- Signing memakai remote credentials EAS yang sudah ada, bukan key baru. Pembandingan langsung dengan sertifikat binary APK 1.0.0 belum tersedia karena artifact lamanya mengembalikan HTTP 404 setelah redirect. Jangan menyatakan sertifikat kedua binary sudah dibandingkan.
- Browser automation memakai profil Brave yang sedang terkunci; browser pengguna tidak ditutup. Verifikasi distribusi memakai readback database dan HTTP publik, bukan klaim klik tombol browser.
