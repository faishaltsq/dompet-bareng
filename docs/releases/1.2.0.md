## Perubahan

- Delapan PNG maskot memiliki background transparan; detail putih yang tertutup outline, termasuk mata, dipertahankan. Empat pasang duplikat tetap identik.
- Kartu solid hijau/biru/kuning/merah muda mengikuti mood, dengan maskot menyatu pada dekorasi kartu.
- **2×2:** nama dompet, pengeluaran hari ini, saran singkat, dan maskot tanpa menutupi nominal.
- **4×2:** nominal dominan, jumlah transaksi pengeluaran, saran dua baris, dan maskot besar. Pada tinggi minimum, jumlah transaksi digabung ke label hari ini.
- **4×4:** ringkasan hari ini, pemasukan dan pengeluaran bulan ini, selisih bulanan, kategori pengeluaran terbesar, serta saran lebih lengkap.
- Tiga pilihan ukuran tersedia dari settings dan provider launcher. Nama `OtterWidget` dipertahankan untuk widget sedang yang sudah terpasang.
- Layout menggunakan ukuran aktual dalam dp. Cache lama tetap terbaca; detail bulanan yang belum diketahui ditampilkan sebagai `—`, bukan pemasukan/net rekaan.
- Data mengikuti dompet aktif, bulan dan tanggal lokal; cache harian kedaluwarsa meminta pengguna membuka aplikasi. Saran tetap lokal tanpa API AI.

- Verifikasi render memakai implementasi native widget pada APK debug emulator. Binary standalone 1.2.0 sudah lulus verifikasi statis di atas, tetapi cold-start/smoke test binary release tidak dijalankan: emulator berisi instalasi/data debug yang dipertahankan dan RAM host terbatas.
- Provider baru telah diverifikasi melalui hasil prebuild, manifest, DEX, dan XML di binary release; pemasangan APK 1.2.0 di Samsung pengguna belum diamati langsung.
- Review subagent otomatis terhenti; pemeriksaan spesifikasi dan integrasi dilanjutkan langsung oleh controller.
