ATURAN GLOBAL DESAIN (Wajib disertakan di setiap prompt v0)
--------------------------------------------------------------------------------
Aesthetic: Modern Minimalist Fintech Mobile App (inspired by Wise, Linear, and Revolut).
Strict Constraints:
- NO EMOJIS anywhere. Use only crisp vector icons from 'lucide-react' (size 16-20px, strokeWidth 1.5).
- Typography: Plus Jakarta Sans / Inter. Hierarchy strictly defined by font weight (500, 600, 700) and muted colors, not oversized fonts.
- Colors: Crisp neutral background (#F8FAFC), card white (#FFFFFF), borders 1px subtle (#E2E8F0 / #CBD5E1), primary dark text (#0F172A), muted labels (#64748B), single brand accent (Emerald #059669 or Slate #0F172A), expense (#EF4444), income (#10B981).
- Layout: 390px iPhone mobile viewport, subtle 1px border cards, 12-16px border-radius, no aggressive neon gradients or bloated drop-shadows.
- Navigation: 3 bottom tabs (Beranda, Statistik, Pengaturan).

PROMPT 1: LAYAR BERANDA (HOME SCREEN)
--------------------------------------------------------------------------------
Design a modern minimalist mobile home screen for "DompetBareng", a shared expense tracking app.

Follow the global design rules (NO EMOJIS, use lucide-react icons, clean fintech slate/emerald palette, 390px mobile frame).

Key Sections to include:
1. Top Bar:
   - Left: User avatar (subtle initials or clean photo) + "Hi, [Name]" in 13px muted text, bold name below.
   - Center/Right: Subtle workspace badge with chevron dropdown (e.g., "Kas Keluarga" + ChevronDown icon) to switch wallets.
   - Far Right: Clean Bell icon with a tiny red unread notification dot.

2. Hero Balance Card (Single sleek white card with 1px border):
   - Label: "Total Saldo Bersih" with an eye toggle icon to hide/show balance.
   - Large formatted Rupiah: "Rp 14.850.000".
   - Split row below:
     * Income this month: "Rp 22.000.000" with a tiny green ArrowDownLeft icon in a soft green circle.
     * Expense this month: "Rp 7.150.000" with a tiny red ArrowUpRight icon in a soft red circle.

3. Quick Action Bar (3 pill buttons):
   - "+ Catat Pengeluaran" (high contrast primary button)
   - "+ Pemasukan" (subtle secondary button)
   - "Pindah Dompet" (outline button with RefreshCw or Wallet icon)

4. Filter Chips:
   - Horizontal pills: "Bulan Ini" (active state), "Minggu Ini", "Hari Ini", "Semua".

5. Transaction History List:
   - Section header: "Transaksi Terbaru" with a "Lihat Semua" link.
   - Transaction rows:
     * Category vector icon in 36px subtle rounded background (e.g., Utensils for food, Car for transport, ShoppingBag for groceries, Zap for bills).
     * Middle: Transaction name (e.g., "Belanja Mingguan"), subtitle showing "Dicatat oleh Sarah • 14 Sep", and a receipt icon if an attachment exists.
     * Right: Formatted amount (-Rp 350.000 in red or +Rp 5.000.000 in green).

6. Floating Companion Indicator:
   - Subtle floating pill or circular mascot dock in the bottom-right corner with a small health badge ("Keuangan Sehat: 82%").
